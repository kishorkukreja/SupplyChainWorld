# Offline smoke experiment

Run `python scripts/run_smoke.py` from the repository. The default experiment uses 100 instances and writes case-level artifacts to `/workspace/SupplyChainWorld-private`, outside the repository. `--count`, `--private-root` and `--public-report` override output settings. Private roots inside the repository are rejected.

A cryptographically generated seed is persisted in the external private store on first use, then reused for deterministic reruns. The frozen manifest contains the seed, preassigned lineage/split metadata, task records and world hashes. It is written before baseline/agent execution; reruns reject any input change against that frozen manifest. Public output includes its SHA-256 hash, never the seed or evaluation cases. Preserve the private directory to reproduce the exact experiment; a fresh directory creates a new population.

The generator assigns all source/template ancestry before expansion and uses different item cardinalities across train/development/evaluation. Cross-split exact/structural/lineage overlap blocks execution; semantic flags also block the smoke command pending explicit review. The experiment runs exhaustive and greedy baselines and a deterministic agent that reconstructs inputs from five permitted visible tool reads. It checks every final submission independently, replays the recorded environment events and runs admission before exporting accepted training records. Development/evaluation records are protected from training export. Three corrupted artifact-hash probes verify admission rejection.

`evidence/issue-11-summary.json` contains aggregate measurements. Private `case-*.json` files contain actual worlds, tasks, generation truth, both baselines, observable actions/results, checker results and admission decisions; `training.jsonl` contains accepted train messages with loss masks and provenance. None of these files is published. The offline agent uses an exhaustive optimizer and is not an LLM; zero provider calls/tokens/cost reflects that fact. This small synthetic experiment establishes integration behavior, not model capability or generalization. Split-specific item cardinalities deliberately prevent structural contamination and also create distribution shift.

Run focused verification with `PYTHONPATH=src python -m unittest tests.test_smoke -v`. It checks actual end-to-end execution, deterministic reruns, training-only export, corruption rejection and private-store separation.
