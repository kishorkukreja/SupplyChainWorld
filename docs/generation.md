# Structured generation

`PYTHONPATH=src python -m unittest discover -s tests -p test_generation.py -v`

`generate_candidate(seed, lineage, split, *, variant=None, outcome=None)` returns a `Candidate` with validated `World`, `Task`, and a separate `private` construction record. Register lineage ancestry before calling this low-level function. `Candidate.private` contains the reference result, independent verification, generator provenance, and variation tags. Never pass it to an agent. `public_bundle()` renders only training worlds, sanitized task metadata and public artifacts; it raises for development/evaluation. Persist protected inputs and all construction truth outside the repository using the lineage private store. This is an application boundary; arbitrary executable adapters still need OS isolation.

`generate_population(count=100, seed=20261102, *, lineage_assignments=None, max_attempts_per_candidate=3)` returns `GenerationBatch(candidates, rejection_counts, attempted, lineage_manifest)`. It assigns all ancestry before expansion. Default families have two, three and four items respectively in train/development/evaluation, providing actual structural separation rather than renamed templates. Default split counts are 60/20/20 for 100 candidates. Optional assignments are a mapping from each split to `lineage.Assignment`; shared source/template/ancestor records across splits fail even when supplied lineage IDs differ.

The generator varies usable/held stock, on-time/late inbound, qualified versus late/unqualified quotes, MOQ and order multiples, supplier fixed fees, variable freight, a binding optimal budget, supplier-spend concentration and required permitted excess. All worlds have multiple items and three suppliers. Independent outcome selection creates awards, missing-commercial-term clarification and capacity-shortfall infeasibility. Quotes remain small enough for exhaustive reference enumeration. Worlds are constructed before task wording and artifacts; no reference fixture answers are read.

Admission here checks typed schemas, proven solver outcome matching the intended type and independent business verification of the reference submission. Unknown, timeout and wrong-type solver results are rejected. Bounded retries retain variant and intended type, use a fresh seed, and count each failed attempt by reason. A short batch is explicit in `len(candidates)` and must not be mistaken for the requested count. Generation truth is not an observed agent trajectory; full trajectory admission and replay belong to the admission module.

The default smoke population has no cross-split flags under the current exact, structural and request-token overlap checker. This small fixed family space does not establish semantic independence or broad procurement coverage. Domain review and expansion beyond bounded integral enumeration remain future work.
